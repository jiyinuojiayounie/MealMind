# 盲盒候选审核表 · 第二批

本批新增 24 道一人份草稿，与原先产品负责人选定的 9 道开发候选组成 33 道。第二批目录放在 frontend/src/data/blind-box-batch-02.json，仅供盲盒开发预览。新菜均待负责人内容审核、实做和包装标签核验。产品内容审批、目录审核状态和过敏原证据分别记录。

用量是单人份改编或原创估算，耗时包含草稿给出的备料和烹饪。熟饭、解冻等前置条件单列。确定来自食材的过敏原按含有记录；其余风险和交叉接触仍待核验。

从 v4 余下的草稿中暂不引入独立配菜、近似组合和用时较长的选项，例如蒜蓉小白菜、冬瓜姜汤和小米南瓜粥。本批覆盖冷餐、烙饼、蒸制、盖饭、拌饭、汤粉、凉面、炖菜和烤盘餐。日式和韩式条目采用家常简化做法。[HowToCook 许可原文](https://github.com/Anduin2017/HowToCook/blob/master/LICENSE)
